# GTM для QNAP

Установочные пакеты GTM и каталог приложений QNAP App Center.

## Установка и обновление

Пакеты находятся в [GitHub Releases](https://github.com/juranart/gtm-releases/releases).

В QNAP App Center откройте **Настройки → Репозиторий приложений → Добавить**:

- Имя: `GTM`
- URL: `https://github.com/juranart/gtm-releases/releases/latest/download/repo.xml`

Каталог устанавливает и обновляет **Bootstrap** — загрузчик GTM. В QTS используется отдельная версия пакета: Bootstrap 1.2.16 соответствует QPKG 4.2.16.

**Core** и **WebUI** поставляются отдельными файлами `.capoo-update`. В GTM откройте **Система и обновления**, загрузите и активируйте сначала Core, затем WebUI из одного релиза. Обновление Core перезапускает действующие MT5.

Первый релиз рассчитан на обновление существующей установки. Для нового NAS дополнительно нужны совместимые Runtime и Bridge; эти пакеты в первый релиз не включены.

## Состав релизов

- `.qpkg` — Bootstrap для QNAP x86_64, QTS 5.0 и новее.
- `.capoo-update` — отдельные компоненты GTM.
- `repo.xml` — каталог App Center с точными ссылками на версии пакетов.
- `SHA256SUMS.txt` — контрольные суммы опубликованных файлов.

В репозитории размещены установочные материалы. Данные аккаунтов, пароли, журналы NAS и рабочие каталоги MT5 не публикуются.

Подробности исправлений и статус проверок приведены в описании каждого релиза.
